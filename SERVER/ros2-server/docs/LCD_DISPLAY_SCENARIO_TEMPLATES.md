# LCD 표시 시나리오별 템플릿 제안서

**작성일**: 2025-01-22  
**목적**: 다양한 상황에 맞는 LCD 표시 템플릿 제안

---

## 개요

로봇이 다양한 상황에서 어르신과 상호작용할 때, 상황에 맞는 적절한 정보를 LCD에 표시하여 어르신과 보호자, 직원들이 쉽게 이해할 수 있도록 합니다.

---

## 시나리오별 템플릿

### 1. 아침인사 시나리오

**상황**: 로봇이 어르신을 처음 만나거나 아침에 인사할 때

**표시 목적**: 친근한 인사와 함께 오늘의 날짜, 날씨 등 기본 정보 제공

#### 템플릿 1: 기본 인사형 (권장)

```
타이틀: 안녕하세요! [애칭] 어르신
라인1: 오늘은 2025년 1월 22일
라인2: 화요일, 맑은 날씨입니다
라인3: 좋은 하루 되세요!
타임스탬프: 2025-01-22 08:00:00
```

**특징**:
- 친근하고 따뜻한 인사
- 날짜와 요일 정보
- 날씨 정보 (선택적)
- 긍정적인 메시지

#### 템플릿 2: 개인화된 인사형

```
타이틀: [애칭] 어르신, 안녕하세요!
라인1: 오늘도 건강한 하루 되세요
라인2: 생활실: 3층 302호 A번
라인3: 오늘 첫 약물 복용: 08:00
타임스탬프: 2025-01-22 08:00:00
```

**특징**:
- 개인화된 인사
- 생활실 정보로 위치 확인
- 다음 약물 복용 시간 안내

#### 템플릿 3: 간단한 인사형

```
타이틀: 안녕하세요!
라인1: [애칭] 어르신
라인2: 좋은 아침입니다
타임스탬프: 2025-01-22 08:00:00
```

**특징**:
- 매우 간단하고 명확
- 작은 화면에 적합

### 2. 식사 지원 시나리오

**상황**: 식사 시간에 어르신을 도와주거나 식사 정보를 안내할 때

**표시 목적**: 식사 메뉴, 식사 시간, 식이 제한사항 안내

#### 템플릿 1: 식사 메뉴 안내형 (권장)

```
타이틀: 식사 시간입니다
라인1: 오늘의 메뉴: 된장찌개
라인2: 저염식, 당뇨식 준비
라인3: 천천히 드세요
타임스탬프: 2025-01-22 12:00:00
```

**특징**:
- 오늘의 식사 메뉴 표시
- 식이 제한사항 명시
- 친절한 안내 메시지

#### 템플릿 2: 식사 시간 안내형

```
타이틀: [애칭] 어르신 식사 시간
라인1: 점심 식사: 12:00
라인2: 저염식, 부드러운 음식
라인3: 식사 도움이 필요하시면 말씀해주세요
타임스탬프: 2025-01-22 11:50:00
```

**특징**:
- 식사 시간 명확히 표시
- 식이 제한사항 안내
- 도움 요청 안내

#### 템플릿 3: 식사 진행형

```
타이틀: 식사 중
라인1: 천천히 드시고
라인2: 꼭꼭 씹어 드세요
라인3: 물도 충분히 드세요
타임스탬프: 2025-01-22 12:15:00
```

**특징**:
- 식사 중 안전 주의사항
- 간단하고 명확한 메시지

### 3. 맞춤형 이동식 대화 시나리오

```
타임스탬프: 2025-01-22 14:30:00
```

**특징**:
- 현재 대화 주제 표시
- 이동 목적지 명시
- 안전 주의사항

#### 템플릿 2: 이동 경로 안내형

```
타이틀: 이동 중
```

**특징**:
- 이동 경로 상세 표시

#### 템플릿 3: 대화 요약형

```
타이틀: 대화 중
라인1: [애칭] 어르신
라인2: 이야기 나누는 중
라인3: 안전하게 이동 중
타임스탬프: 2025-01-22 14:40:00
```

**특징**:
- 간단하고 명확
- 현재 상태만 표시

**상황**: DL YOLO가 어르신의 배회를 감지했을 때

**표시 목적**: 어르신 정보, 현재 위치, 생활실 복귀 안내

#### 템플릿 1: 배회 감지 알림형 (권장)

```

라인1: 위치: 1층 복도
라인2: 생활실: 3층 302호 A번
라인3: 안전을 위해 생활실로 복귀해주세요
타임스탬프: 2025-01-22 15:30:00
```

**특징**:
- ⚠️ 표시로 주의 환기
- 현재 위치 명시
- 생활실 정보 제공
- 복귀 안내

#### 템플릿 2: 긴급 안내형

```
타이틀: ⚠️ 배회 감지
라인1: [애칭] 어르신
라인2: 현재: 1층 복도
라인3: 생활실로 안내 중
타임스탬프: 2025-01-22 15:30:00
```

**특징**:
- 간결하고 명확
- 긴급 상황 강조

#### 템플릿 3: 상세 정보형

```
타이틀: ⚠️ [애칭] 어르신 배회 감지
라인1: 위치: 1층 복도 (카메라: camera_001)
라인2: 생활실: 3층 302호 A번
라인3: 낙상 위험 높음 - 보행기 사용 필요
라인4: 생활실로 복귀 안내 중
타임스탬프: 2025-01-22 15:30:00
```

**특징**:
- 상세한 정보 제공
- 특이사항 포함
- 안전 주의사항 강조

## 템플릿 선택 가이드

### 상황별 권장 템플릿

| 시나리오 | 권장 템플릿 | 대안 |
|---------|-----------|------|
| 아침인사 | 기본 인사형 | 개인화된 인사형 |
| 식사 지원 | 식사 메뉴 안내형 | 식사 시간 안내형 |
| 맞춤형 이동식 대화 | 대화 주제 표시형 | 이동 경로 안내형 |
| 배회 감지 | 배회 감지 알림형 | 긴급 안내형 |
| 면회객 안내 | 면회객 정보 표시형 | 면회 준비 안내형 |

### 템플릿 선택 기준

1. **정보량**: 화면 크기에 따라 적절한 정보량 선택
2. **긴급도**: 긴급한 상황(배회 감지)은 ⚠️ 표시 사용
3. **대상**: 어르신이 직접 보는 경우 vs 직원/보호자가 보는 경우
4. **상황**: 정적 정보 vs 동적 정보 (이동 중 등)

### Python 코드 예시

```python
def format_morning_greeting(resident_data: dict, weather: str = None) -> dict:
    """아침인사 템플릿"""
    nickname = resident_data.get("nickname") or resident_data.get("user_name")
    today = datetime.now()
    
    lines = [
        f"오늘은 {today.strftime('%Y년 %m월 %d일')}",
        f"{today.strftime('%A')}, {weather or '맑은'} 날씨입니다",
        "좋은 하루 되세요!"
    ]
    
    return {
        "title": f"안녕하세요! {nickname} 어르신",
        "lines": lines,
        "show_timestamp": True
    }

def format_meal_assistance(resident_data: dict, menu: str, meal_time: str) -> dict:
    """식사 지원 템플릿"""
    dietary_restrictions = resident_data.get('dietary_restrictions', {})
    restrictions = dietary_restrictions.get('restrictions', [])
    
    lines = [
        f"오늘의 메뉴: {menu}",
        f"{', '.join(restrictions)} 준비" if restrictions else "식사 준비 완료",
        "천천히 드세요"
    ]
    
    return {
        "title": "식사 시간입니다",
        "lines": lines,
        "show_timestamp": True
    }

def format_wandering_detection(resident_data: dict, location: str, camera_id: str) -> dict:
    """배회 감지 템플릿"""
    nickname = resident_data.get("nickname") or resident_data.get("user_name")
    room_info = format_room_info(resident_data)
    
    lines = [
        f"위치: {location}",
        f"생활실: {room_info}",
        "안전을 위해 생활실로 복귀해주세요"
    ]
    
    return {
        "title": f"⚠️ {nickname} 어르신 발견",
        "lines": lines,
        "show_timestamp": True
    }

def format_visitor_guidance(resident_data: dict, visitor_name: str, 
                           visitor_relationship: str, meeting_room: str) -> dict:
    """면회객 안내 템플릿"""
    nickname = resident_data.get("nickname") or resident_data.get("user_name")
    
    lines = [
        f"방문자: {visitor_name} ({visitor_relationship})",
        f"{nickname} 어르신 면회",
        f"{meeting_room}로 안내 중"
    ]
    
    return {
        "title": "면회객 안내",
        "lines": lines,
        "show_timestamp": True
    }
```

## 템플릿 커스터마이징

### 개인화 옵션

1. **애칭 사용**: 공식 이름 대신 애칭 사용
2. **특이사항 반영**: 낙상 위험, 보행기 사용 등 특이사항 표시
3. **시간대별 메시지**: 아침/점심/저녁에 맞는 인사말
4. **날씨 정보**: 실시간 날씨 정보 통합

### 동적 정보 통합

1. **실시간 위치**: 현재 위치 정보
2. **약물 스케줄**: 다음 약물 복용 시간
3. **식사 메뉴**: 오늘의 식사 메뉴
4. **면회객 정보**: 방문 예정 면회객 정보

## 결론

각 시나리오에 맞는 템플릿을 제공하여 상황에 적절한 정보를 LCD에 표시할 수 있습니다. 템플릿은 필요에 따라 커스터마이징하여 사용할 수 있으며, 어르신의 특이사항과 상황에 맞게 동적으로 조정됩니다.
