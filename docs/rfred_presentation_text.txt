1. Project Suggestions & Implications

Practical Feasibility
Proof of Concept (PoC)
We demonstrated that a single robot can handle multi-domain tasks (Patrol + Delivery + Care) in a physical nursing home set, proving that automation is ready for field testing.
Proposal :

Standardized Architecture
ROS2 Modular Design
By decoupling the 'Vision Node', 'Control Node', and 'LLM Service', the system allows for easy hardware upgrades (e.g., changing the robot base or camera) without rewriting core logic.
Proposal :

Care-Centric Innovation
Beyond Labor Saving
We shifted the focus from "replacing humans" to "augmenting care". The system's ability to log emotions and prevent falls adds value that human staff alone cannot provide 24/7.
Proposal :
