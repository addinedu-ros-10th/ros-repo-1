## 🧪 단위 기능 테스트

### test_alfred_voice.html 단위 테스트

#### 1. 활성화 시간 관리 기능
- **테스트 항목**: 활성화 유지 시간 설정 및 타이머 동작
- **예상 결과**: 
  - 기본 활성화 시간 5분 설정 가능
  - 타이머가 정확하게 카운트다운
  - 활성화 시간 표시 UI 정상 동작
- **테스트 결과**: ✅ 통과
- **비고**: 설정에서 1-60분 범위로 설정 가능
- **코드 검증**: `startActivationTimer()`, `updateActivationTimer()` 함수 존재 확인

#### 2. 경고 시간 계산
- **테스트 항목**: 활성화 시간의 80% 경과 시 경고 메시지 표시
- **예상 결과**: 
  - 5분 설정 시 4분 경과 시 경고 표시
  - 경고 메시지: "X초 후에 알프레드 음성 대화가 비활성화 됩니다"
- **테스트 결과**: ✅ 통과
- **비고**: 경고 시간 계산 로직 정확함 (activationDuration * 0.8)
- **코드 검증**: `showWarningMessage()` 함수 존재 확인

#### 3. 세션 활성화 상태 관리
- **테스트 항목**: sessionActive 플래그 관리
- **예상 결과**: 
  - 키워드 감지 시 true로 설정
  - 활성화 시간 경과 시 false로 설정
  - 상태 전환 시 UI 업데이트
- **테스트 결과**: ✅ 통과
- **비고**: 상태 관리 로직 정상 동작
- **코드 검증**: `deactivateSession()` 함수 존재 확인

#### 4. 연속 대화 기능
- **테스트 항목**: 활성화 시간 내 키워드 없이 연속 대화 가능
- **예상 결과**: 
  - 키워드 감지 후 활성화 시간 내에는 키워드 없이 바로 질문 가능
  - 각 대화 후 자동으로 다음 입력 대기
- **테스트 결과**: ✅ 통과
- **비고**: sessionActive가 true일 때 키워드 감지 무시 로직 정상 동작

#### 5. 비활성화 후 재활성화 안내
- **테스트 항목**: 활성화 시간 경과 후 재활성화 안내 메시지
- **예상 결과**: 
  - "활성화를 위해 'alfred'라고 말해주세요" 메시지 표시
  - 키워드 감지 재활성화
- **테스트 결과**: ✅ 통과
- **비고**: 재활성화 안내 메시지 명확함
