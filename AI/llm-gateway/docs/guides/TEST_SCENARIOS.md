## test_alfred_voice.html 사용 시나리오

### 시나리오 1: 키워드 활성화 → 연속 대화

**목적**: 키워드 감지 후 일정 시간 동안 키워드 없이 연속 대화 가능

**단계**:
1. "시작" 버튼 클릭 → 마이크 권한 허용
2. "alfred"라고 말하기 → 키워드 감지됨
3. 한국어로 질문하기 (예: "안녕하세요")
4. AI 응답 듣기
5. **연속 대화**: 키워드 없이 바로 다음 질문하기 (예: "오늘 날씨는?")
6. AI 응답 듣기
7. 반복 (활성화 시간 내)

**예상 동작**:
- 키워드 감지 후 활성화 상태 유지 (기본 5분)
- 활성화 시간 내에는 키워드 없이 바로 질문 가능
- 각 대화 후 자동으로 다음 입력 대기
- 활성화 시간의 80% 경과 시 경고 메시지 표시

**비정상 동작 (수정 전)**:
- 키워드 감지 후 한 번만 대화 가능
- 이후 키워드를 다시 말해야 함

---

### 시나리오 2: 키워드 활성화 → 비활성화 경고 → 재활성화 안내

**목적**: 활성화 시간 경과 시 사용자에게 명확한 안내 제공

**단계**:
1. 키워드 활성화
2. 대화 진행
3. 활성화 시간의 80% 경과 시 경고 메시지 표시
   - 예: "40초 후에 알프레드 음성 대화가 비활성화 됩니다"
4. 활성화 시간 완전 경과 시 비활성화
5. 재활성화 안내 메시지 표시
   - 예: "활성화를 위해 'alfred'라고 말해주세요"

**예상 동작**:
- 경고 메시지가 명확하게 표시됨
- 재활성화 방법이 명확하게 안내됨
- 사용자가 다음 행동을 쉽게 이해할 수 있음

---

### 시나리오 3: 키워드 활성화 → 대화 → 오디오 재생 → 자동 대기 모드

**목적**: 오디오 재생 완료 후 자동으로 다음 입력 대기

**단계**:
1. 키워드 활성화
2. 질문하기
3. AI 응답 오디오 재생
4. 오디오 재생 완료
5. 자동으로 다음 입력 대기 상태로 전환
6. 키워드 없이 바로 다음 질문 가능 (활성화 시간 내)

**예상 동작**:
- 오디오 재생 완료 후 자동 대기 모드로 전환
- 상태 표시가 명확함
- 다음 질문을 바로 할 수 있음

## test_voiceprint_management.html 사용 시나리오

### 시나리오 1: 음성 지문 등록 → 초기화 → 새로 등록

**목적**: 등록 과정을 초기화하고 새로운 등록을 시작

**단계**:
1. 기준 키워드 입력 (예: "alfred")
2. "키워드 녹음 시작" 버튼 클릭
3. 키워드 말하기
4. "녹음 중지" 버튼 클릭
5. STT 결과 확인 및 수정
6. "음성 지문 등록" 버튼 클릭
7. 등록 완료
8. **"초기화" 버튼 클릭** → 입력 필드 초기화, 녹음 상태 초기화
9. **"새로 등록" 버튼 클릭** → 새로운 등록 시작

**예상 동작**:
- "초기화" 버튼은 언제든 사용 가능
- "새로 등록" 버튼은 대기 상태에서만 활성화
- 등록된 데이터는 유지됨 (초기화는 등록 과정만 초기화)
- 초기화 후 바로 새로 등록 가능

**비정상 동작 (수정 전)**:
- 등록 후 상태가 불명확함
- 다시 등록하려면 어떻게 해야 할지 불명확함

---

### 시나리오 2: 음성 지문 등록 → 목록 확인 → 테스트

**목적**: 등록된 음성 지문을 확인하고 테스트

**단계**:
1. 음성 지문 등록
2. "목록 새로고침" 버튼 클릭
3. 등록된 음성 지문 목록 확인
4. 특정 음성 지문의 "테스트" 버튼 클릭
5. 테스트 결과 확인

**예상 동작**:
- 등록 후 목록이 자동으로 업데이트됨
- 테스트 결과가 명확하게 표시됨

---

### 시나리오 3: 음성 지문 등록 → 중지 → 재시작

**목적**: 등록 과정 중 중지하고 재시작

**단계**:
1. "키워드 녹음 시작" 버튼 클릭
2. 녹음 중
3. "녹음 중지" 버튼 클릭
4. 상태 확인
5. "새로 등록" 버튼 클릭하여 재시작

**예상 동작**:
- 중지 후 상태가 명확하게 표시됨
- 재시작 방법이 명확함
- 버튼 상태가 적절하게 관리됨

## UI/UX 개선 사항

### test_alfred_voice.html
1. **활성화 시간 표시**: 남은 활성화 시간을 시각적으로 표시
2. **경고 메시지**: 비활성화 전 경고 메시지 표시
3. **재활성화 안내**: 비활성화 후 명확한 재활성화 방법 안내
4. **상태 전환**: 각 상태 전환 시 명확한 피드백

### test_voiceprint_management.html
1. **초기화 버튼**: 등록 과정을 초기 상태로 되돌림 (데이터는 유지)
2. **새로 등록 버튼**: 대기 상태에서만 활성화
3. **상태 표시**: 현재 상태를 명확하게 표시
4. **버튼 상태 관리**: 각 상황에 맞는 버튼 활성화/비활성화
