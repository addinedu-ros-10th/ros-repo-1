# 키워드 인식 및 음성 지문 기능 검증 가이드

## 개요
이 문서는 키워드 인식 및 음성 지문 기능의 개발 완료 상태를 검증하는 방법을 안내합니다.

## 개발 완료 사항

### 1. UI 개선 사항 ✅

#### 1.1 키워드 매칭 유사도 표시
- 키워드 감지 시 유사도 배지 표시
- 유사도에 따른 색상 변경:
  - 90% 이상: 초록색
  - 70-90%: 노란색
  - 70% 미만: 빨간색

#### 1.2 음성 지문 등록 상태 표시
- 등록 성공 시: 초록색 배경, 성공 메시지
- 등록 실패 시: 빨간색 배경, 에러 메시지
- 5초 후 자동 숨김

#### 1.3 등록된 음성 지문 개수 표시
- "등록된 음성 지문: N개" 표시
- 시작 버튼 클릭 시 자동 조회 및 표시

### 2. 기능 개선 사항 ✅

#### 2.1 음성 지문 등록 로직 개선
- 키워드 감지 후 첫 질문 시 자동 등록
- voiceprint_id가 null이거나 새로운 STT 결과일 때 등록
- 등록 성공/실패 시 UI 알림

#### 2.2 키워드 확인 개선
- 서버 API를 통한 키워드 확인
- 유사도 기반 Fuzzy Matching
- 등록된 voiceprint와 매칭

## 검증 방법

### 방법 1: 테스트 UI 사용

1. **서버 실행**
   ```bash
   cd AI/llm-gateway
   python -m uvicorn src.main:app --reload
   ```

2. **테스트 UI 접속**
   - 브라우저에서 `http://localhost:8000/tests/test_alfred_voice.html` 접속

3. **기능 검증**
   - "시작" 버튼 클릭
   - "alfred"라고 말하기

### 방법 3: 데이터베이스 직접 확인

1. **PostgreSQL에 접속**
   ```bash
   psql -U your_username -d your_database
   ```

2. **테이블 확인**
   ```sql
   -- 테이블 존재 확인
   SELECT table_name 
   FROM information_schema.tables 
   WHERE table_name = 'keyword_voiceprints';

   -- 등록된 음성 지문 조회
   SELECT id, base_keyword, stt_keyword, session_id, 
          is_active, created_at, 
          LENGTH(audio_data) as audio_size
   FROM keyword_voiceprints
   ORDER BY created_at DESC;

   -- 특정 키워드의 음성 지문 개수
   SELECT base_keyword, COUNT(*) as count
   FROM keyword_voiceprints
   WHERE is_active = true
   GROUP BY base_keyword;
   ```

## 기능 검증 체크리스트

### 기본 기능
- [ ] 키워드 "alfred" 정확히 말하면 인식됨
- [ ] 키워드 포함된 문장에서도 인식됨 (예: "hello alfred")
- [ ] 유사한 키워드도 인식됨 (예: "rarpred")
- [ ] 완전히 다른 단어는 인식되지 않음

### UI 피드백
- [ ] 키워드 감지 시 유사도 배지 표시
- [ ] 유사도에 따른 색상 변경 확인
- [ ] 음성 지문 등록 성공 시 초록색 메시지 표시
- [ ] 음성 지문 등록 실패 시 빨간색 메시지 표시
- [ ] 등록된 음성 지문 개수 표시

### 음성 지문 기능
- [ ] 키워드 감지 후 첫 질문 시 음성 지문 자동 등록
- [ ] 등록된 음성 지문이 DB에 저장됨
- [ ] 동일한 키워드로 다시 말하면 등록된 voiceprint와 매칭
- [ ] 음성 지문 조회 API로 등록된 데이터 확인 가능

## 문제 해결

### 문제: 서버에 연결할 수 없음
**해결**: 서버가 실행 중인지 확인
```bash
cd AI/llm-gateway
python -m uvicorn src.main:app --reload
```

### 문제: 데이터베이스가 초기화되지 않음
**해결**: 서버 로그 확인 및 DB 연결 설정 확인
- 환경 변수 확인: `DATABASE_URL`
- 서버 시작 시 자동으로 테이블 생성됨

### 문제: 음성 지문이 등록되지 않음
**해결**: 
1. 브라우저 콘솔에서 에러 메시지 확인
2. 서버 로그에서 API 호출 확인
3. DB에 실제로 저장되었는지 확인

### 문제: UI에 변경사항이 보이지 않음
**해결**:
1. 브라우저 캐시 삭제 후 새로고침 (Ctrl+Shift+R)
2. 서버가 최신 파일을 서빙하는지 확인
3. 브라우저 개발자 도구에서 콘솔 에러 확인
