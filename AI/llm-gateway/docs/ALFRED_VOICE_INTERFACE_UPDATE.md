# Alfred 키워드 기반 음성 인터페이스 개발 리포트

## 개요
키워드 기반 음성 인터페이스 테스트 프로그램을 개발하고, 키워드 감지 개선 및 연속 대화 지원 기능을 구현했습니다.

## 주요 개발 내용

### 1. 키워드 기반 음성 인터페이스 테스트 프로그램 생성

**파일**: `tests/user_testing/test_alfred_voice.html`

#### 기능
- **키워드 감지**: Web Speech API를 사용한 영어 "alfred" 키워드 감지
- **음성 처리**: STT → ChatGPT → TTS 전체 프로세스 통합
- **JSON 응답 처리**: Base64 인코딩된 오디오 디코딩 및 재생
- **텍스트-음성 동기화**: 오디오 재생 시간에 맞춰 텍스트 하이라이트
- **실시간 오디오 레벨 미터**: 마이크 입력 데시벨 실시간 표시
- **설정 패널**: 파라미터 조절 기능 (녹음 시간, 대기 시간, 자동 대기 모드)

### 2. 정적 파일 서빙 구성 (404 에러 해결)

#### 문제
- 테스트 페이지 접근 시 404 에러 발생
- `/tests/user_testing/test_alfred_voice.html` 경로로 접근 불가

#### 해결
- **FastAPI 정적 파일 서빙 추가** (`src/main.py`)
  - `StaticFiles` import 추가
  - `/tests` 경로에 `tests/user_testing` 디렉토리 마운트
  - 로컬 및 Docker 환경 모두 지원
  
- **Dockerfile 수정**
  - `tests/` 디렉토리 복사 추가
  - 정적 파일 서빙을 위한 파일 포함
  
- **.dockerignore 수정**
  - `tests/` 디렉토리 제외 주석 처리
  - 빌드 컨텍스트에 포함되도록 수정

### 3. 키워드 감지 개선

#### 문제
- 키워드가 한번에 잘 인식되지 않음
- 여러 번 불러야 인식되는 현상

#### 해결
- **유연한 키워드 매칭**
  - 단어 경계를 고려한 정규식 매칭 (`\balfred\b`)
  - 단순 포함 확인 (fallback)
  - interim 결과와 final 결과 모두 확인
  
- **중복 트리거 방지**
  - `sessionActive` 체크로 중복 감지 방지
  - `detectKeyword()` 함수에서 중복 체크 추가
  
- **자동 재시작 개선**
  - `recognition.onend`에서 재시작 로직 개선
  - 재시작 실패 시 재시도 로직 추가

### 4. 연속 대화 지원

#### 문제
- 한번 응답을 받고 나면 다음 대화가 불가능
- 데시벨 미터 UI가 비활성화됨
- 어떤 말을 해도 입력이 이어지지 않음

#### 해결
- **오디오 재생 완료 후 자동 재활성화**
  - `playAudioFromBase64`의 `onended`에서 키워드 감지 재시작
  - 오디오 레벨 측정 자동 재시작
  - `autoWaitMode`가 활성화되어 있으면 자동으로 다음 입력 대기
  
- **오디오 레벨 측정 지속**
  - `audioContext`를 녹음 중에도 유지
  - 녹음 완료 후에도 오디오 레벨 측정 계속 실행
  - `restartAudioLevelMeter()` 함수로 필요 시 재시작
  
- **키워드 감지 재시작**
  - API 응답 처리 후 `recognition` 상태 확인 및 재시작
  - 오디오 재생 완료 후에도 `recognition` 재시작

### 5. 실시간 오디오 레벨 미터 추가

#### 기능
- **Web Audio API 기반 측정**
  - `AnalyserNode`를 사용한 실시간 오디오 레벨 측정
  - RMS (Root Mean Square) 기반 계산
  - 데시벨(dB) 표시
  
- **시각적 피드백**
  - 레벨 바: 녹색(조용) → 노란색(보통) → 빨간색(크게)
  - 숫자 표시: 데시벨 값 실시간 표시
  - 색상 변경: 레벨에 따라 텍스트 색상 변경
  
- **동작 방식**
  - "시작" 버튼 클릭 시 마이크 스트림으로 레벨 측정 시작
  - 키워드 감지 중에도 계속 측정
  - 녹음 중에도 측정 지속
  - "중지" 버튼 클릭 시 측정 중지

### 6. 설정 패널 추가

#### 파라미터 조절 기능
- **자동 녹음 중지 시간**: 1-30초 (기본값: 5초)
- **키워드 감지 후 대기 시간**: 0-5초 (기본값: 0.5초)
- **오디오 재생 완료 후 자동 대기 모드**: 체크박스 (기본값: 활성화)

#### 특징
- 설정값 localStorage에 자동 저장
- 접기/펼치기 기능
- 실시간 적용

## 기술적 개선 사항

### 오디오 레벨 측정 최적화
- **중복 방지**: `audioContext` 재사용, `levelAnimationFrame` 체크
- **스트림 관리**: `microphone` disconnect 후 재연결 방식
- **리소스 관리**: 녹음 완료 후에도 `audioContext` 유지하여 연속 대화 지원

### 키워드 감지 최적화
- **이중 매칭 전략**: 정규식 매칭 + 단순 포함 확인
- **상태 관리**: `sessionActive` 플래그로 중복 감지 방지
- **자동 복구**: 재시작 실패 시 자동 재시도

## 테스트 방법

### 접속
- URL: `http://localhost:8000/tests/test_alfred_voice.html`

### 사용 순서
1. "시작" 버튼 클릭 → 마이크 권한 허용
2. "alfred"라고 영어로 말하기 (키워드 감지)
3. 키워드 감지 후 한국어로 질문하기
4. AI 응답을 텍스트와 음성으로 확인
5. 오디오 재생 완료 후 자동으로 다음 입력 대기
6. 다시 "alfred"라고 말하여 연속 대화 진행

## 브라우저 호환성
- **권장**: Chrome, Edge (최적 성능)
- **필수**: Web Speech API 지원 브라우저

## 알려진 제약사항
- Web Speech API는 브라우저별로 성능이 다를 수 있음
- 키워드 감지 정확도는 환경 소음에 영향을 받을 수 있음
- 오디오 레벨 측정은 브라우저의 마이크 권한이 필요함

## 향후 개선 사항
1. 키워드 감지 임계값 조정 옵션 추가
2. 음성 입력 감도 조절 기능
3. 키워드 커스터마이징 (다른 키워드 사용 가능)
4. 오디오 재생 속도 조절 기능
